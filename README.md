# Harshitha Jonnalagadda — Portfolio

A responsive, cinematic portfolio customized from the supplied React + TypeScript + Vite template. The design keeps a near-black background, neon pink/red lighting, bold typography, a portrait-led hero, scroll animations, project cards, skills, education, certifications, and contact links.

## Requirements
- Node.js 20+ recommended
- npm

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Personalization
- Main portfolio content: `src/data/portfolio.ts`
- Hero layout and portrait reveal: `src/components/Hero.tsx`
- Main theme and styling: `src/index.css`
- Portrait: `public/assets/harshitha-portrait.png`
- Resume PDF: `public/assets/Harshitha_Jonnalagadda_Resume.pdf`

The portfolio content is based on details supplied by Harshitha and the uploaded project presentations. No job experience, awards, grades, or unprovided certification links have been added. The resume PDF is a starter resume generated from the supplied details and can be replaced with a final resume later.
